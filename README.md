# Portafolio — Pablo Huamani

Portafolio web de Pablo Huamani, diseñador gráfico publicitario (branding y productos digitales).

## Uso

Abre `index.html` en el navegador. Es una sola página, sin instalación ni build.

## Cómo hacer cambios

1. Abre el archivo en GitHub y haz clic en el lápiz (✏️).
2. Edita y pulsa **Commit changes**.
3. Elige **"Create a new branch for this commit and start a pull request"**.
4. Revisa el pull request y haz **Merge** hacia `main`.

La rama `main` es la versión publicada.
